# yt-tools

[日本語](./README.ja.md)

Chrome extension that restores YouTube's miniplayer button and optionally blocks Shorts and Playables.

[Privacy policy](./PRIVACY.md)

## Features

- Restores the miniplayer button
- Optionally hides Shorts and opens Shorts in the standard player
- Optionally hides YouTube Playables and redirects minigame pages
- Toggle each feature from the extension popup
- English and Japanese UI
- No data collection or tracking

> [!WARNING]
> Shorts and Playables blocking are disabled by default.

## Installation

1. Clone or download this repository:

```bash
git clone https://github.com/fjt-dev/yt-tools
```

2. Open `chrome://extensions/`
3. Enable **Developer mode**
4. Click **Load unpacked** and select the project folder
