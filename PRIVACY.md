# Privacy Policy / プライバシーポリシー

Effective date / 発効日: 2026-08-27

## English

yt-tools improves the YouTube interface by adding a miniplayer button and, when the user enables them, hiding or redirecting YouTube Shorts and Playables.

### Data processed

- The extension reads the structure and current URL of pages on `https://www.youtube.com/` only to provide its user-facing features.
- The extension stores three feature preferences (`enabled`, `shortsBlocked`, and `playablesBlocked`) locally on the user's device using `chrome.storage.local`.

### Collection, transmission, and sharing

yt-tools does not collect, transmit, sell, or share personal information, browsing history, page content, or usage data. Page information is processed locally and is not retained. The extension contains no analytics, advertising, tracking, account system, or remotely hosted executable code.

### Retention and deletion

Preferences remain in Chrome's local extension storage until the user changes them, clears the extension's data, or uninstalls the extension.

### Limited use

Any information accessed by yt-tools is used only to provide or improve its disclosed, user-facing purpose. The use of information received from Google APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

### Changes and contact

Material changes to this policy will be published on this page with an updated effective date. Questions can be submitted through the [GitHub issue tracker](https://github.com/fjt-dev/yt-tools/issues).

## 日本語

yt-tools は、YouTube にミニプレイヤーボタンを追加し、ユーザーが有効にした場合に YouTube Shorts と Playables を非表示またはリダイレクトする拡張機能です。

### 処理するデータ

- ユーザー向け機能を提供するために限り、`https://www.youtube.com/` 上のページ構造と現在のURLを読み取ります。
- 3つの機能設定（`enabled`、`shortsBlocked`、`playablesBlocked`）を `chrome.storage.local` を使用してユーザーの端末内に保存します。

### 収集・送信・共有

yt-tools は、個人情報、閲覧履歴、ページ内容、利用状況データを収集、外部送信、販売、共有しません。ページ情報は端末内で処理され、保持されません。解析、広告、追跡、アカウント機能、外部でホストされた実行コードは含みません。

### 保持と削除

設定は、ユーザーが変更する、拡張機能のデータを消去する、または拡張機能をアンインストールするまで、Chrome のローカル拡張機能ストレージに保持されます。

### 限定的な利用

yt-tools がアクセスする情報は、公開されているユーザー向けの単一目的を提供または改善するためにのみ使用します。Google API から受け取った情報の利用は、限定的利用の要件を含む Chrome ウェブストアのユーザーデータポリシーに準拠します。

### 変更とお問い合わせ

このポリシーに重要な変更がある場合は、発効日を更新してこのページで公開します。お問い合わせは [GitHub Issues](https://github.com/fjt-dev/yt-tools/issues) から送信できます。
