# yt-tools

[English](./README.md)

YouTubeのミニプレイヤーボタンを復活させ、ShortsとYouTube内のミニゲームを個別にブロックできるChrome拡張機能

## 機能

- YouTubeの動画コントロールバーにミニプレイヤーボタンを自動的に追加します
- Shortsの棚、ナビゲーション項目、検索結果・関連動画内のShortsを非表示にします
- Shortsを通常の動画プレーヤーで開き、プレイリストの位置を維持します
- YouTube Playablesへの入口を非表示にし、ミニゲームページへのアクセスをブロックします
- 拡張機能のポップアップから各機能を個別にオン／オフできます
- ブロッカーをオフにすると、非表示にした項目をその場で復元します
- データ収集や追跡は一切行いません

> [!WARNING]
> Shortsとミニゲームのブロック機能はデフォルトで無効です。必要な機能だけを有効にしてください。

## インストール方法

1. このリポジトリをクローンまたはダウンロードします。

```bash
   git clone https://github.com/fjt-dev/yt-tools
```

2. Chromeを開き、`chrome://extensions/` にアクセスします。
3. **デベロッパーモード**を有効にします（右上のスイッチで切り替え）。
4. **パッケージ化されていない拡張機能を読み込む**をクリックし、プロジェクトフォルダを選択します。
5. これでYouTube上で拡張機能が有効になります。
